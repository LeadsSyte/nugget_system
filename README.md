# 🚀 Google Ads Agent - Ultimate AI Optimization

An intelligent Google Ads automation system powered by Gemini 2.0 Flash that optimizes your campaigns daily with AI-driven decisions.

## ✨ Features

- **🎯 Automated Bid Optimization** - AI analyzes performance and adjusts keyword bids
- **📝 Ad Copy Generation** - Creates and tests new ad variations automatically
- **🔑 Keyword Management** - Discovers new keywords and adds negative keywords
- **📊 Performance Analysis** - Daily performance reports with actionable insights
- **✅ Approval Workflow** - Review and approve AI recommendations before applying
- **📧 Email Notifications** - Daily summaries with performance and pending actions
- **🧠 AI Justifications** - Every decision includes detailed reasoning to prevent hallucinations
- **🔒 Safety Controls** - Multiple safeguards to protect your account

## 🚀 Quick Start

### Step 1: Install Dependencies

```bash
# Install Python packages
pip install -r requirements.txt
```

### Step 2: Configure Credentials

```bash
# Copy the example environment file
cp .env.example .env

# Edit .env and add your credentials
# (See SETUP.md for detailed instructions)
nano .env
```

### Step 3: Run the Agent

```bash
# Run in dry-run mode first (safe, no changes applied)
python run_agent.py
```

### Step 4: Review and Approve Actions

```bash
# Review the approval file generated by the agent
cat approvals/pending_actions_XXXXXX.txt

# Approve or reject actions
python approve_actions.py approvals/pending_actions_XXXXXX.json
```

## ⚙️ Configuration

Edit `config.yaml` to customize the agent's behavior:

### Approval Mode (Recommended to Start)

```yaml
approval:
  enabled: true  # Require your approval before applying changes
  email_notifications: true
```

**After you're comfortable, set `enabled: false` for fully autonomous operation.**

### Bid Management

```yaml
bidding:
  max_bid_change_percent: 20  # Maximum daily bid change
  min_bid: 0.10
  max_bid: 50.00
  auto_apply_bids: true  # Only applies if approval.enabled = false
```

### Safety Settings

```yaml
safety:
  dry_run: false  # Set to true to test without making changes
  max_actions_per_campaign: 10  # Limit actions per campaign
```

## 📊 Daily Workflow

1. **Agent Runs** (via cron job or manually)
   - Analyzes campaign performance
   - Gemini AI generates recommendations
   - Actions are logged with justifications

2. **You Receive Email** with:
   - Performance summary
   - Recommended actions
   - Link to approval file

3. **You Review & Approve**
   - Check AI justifications
   - Approve or reject each action
   - Actions are applied to Google Ads

4. **Rinse & Repeat** daily for continuous optimization

## 🎛️ Autonomous Mode

Once you're comfortable with the agent's decisions:

1. Edit `config.yaml`:
   ```yaml
   approval:
     enabled: false  # Disable approval requirement
   ```

2. The agent will now run fully autonomously
3. You'll still receive daily email reports
4. All decisions are still logged with justifications

## 🐛 Troubleshooting

### "Missing required environment variables"
- Check that `.env` file exists and has all credentials
- See SETUP.md for obtaining Google Ads API credentials

### "No active campaigns found"
- Verify your `GOOGLE_ADS_LOGIN_CUSTOMER_ID` is correct
- Ensure you have active campaigns in your account

### "Google Ads API error"
- Check your developer token is approved
- Verify OAuth2 credentials are valid

### Agent recommendations seem off
- Check the decision logs in `decisions/` for AI justifications
- Adjust thresholds in `config.yaml`
- Report issues with examples
