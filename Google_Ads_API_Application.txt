1. PURPOSE
----------
AI-powered campaign optimization tool for managing client Google Ads accounts.
Analyzes performance data and generates recommendations to improve ROI for
lead generation campaigns. All changes require human approval.


2. HOW IT WORKS
---------------

Step 1: DATA COLLECTION (Read-Only)
   - Fetch campaign performance (impressions, clicks, conversions, cost)
   - Fetch keyword performance (conversions, cost per lead, quality score)
   - Fetch search terms report (identify wasted spend)
   - Fetch ad performance metrics

Step 2: AI ANALYSIS
   - Google Gemini AI analyzes performance data
   - Identifies optimization opportunities:
     * Keywords with high cost per lead → suggest bid decreases
     * Keywords with low cost per lead → suggest bid increases
     * Search terms with clicks but no conversions → suggest as negatives
     * Generate new ad copy variations for testing

Step 3: HUMAN APPROVAL
   - System generates HTML approval interface
   - User reviews each recommendation
   - User clicks "Approve" or "Reject" buttons
   - NO AUTOMATIC CHANGES - 100% human-in-the-loop

Step 4: IMPLEMENTATION
   - Only approved recommendations are applied via Google Ads API
   - Rejected recommendations are blacklisted (not suggested again)
   - All actions logged for audit trail


3. WHAT DATA WE ACCESS
----------------------

READ ACCESS (Required):
✓ Campaign metrics (impressions, clicks, cost, conversions)
✓ Keyword performance (conversions, cost per conversion, quality score)
✓ Search terms report (user queries triggering ads)
✓ Ad performance (headlines, descriptions, metrics)
✓ Ad group data (bids, status, performance)

WRITE ACCESS (Human Approved Only):
✓ Update keyword bids
✓ Create new ads
✓ Add keywords
✓ Add negative keywords

WE DO NOT ACCESS:
✗ Billing information
✗ Personal user data
✗ Competitor data
✗ Accounts we don't manage

--------------------

Goals:

- Continuously test and improve ad copy

Benefits:

9. WHY WE NEED STANDARD ACCESS
------------------------------

Basic Access Limitations:
✗ Cannot access keyword-level performance data
✗ Cannot access search terms report
✗ Cannot see quality scores

Standard Access Needed For:
✓ Keyword performance analysis (conversions, cost per conversion)
✓ Search terms report (identify negative keywords)
✓ Quality score data (improve ad relevance)

Without Standard Access, we can only provide generic suggestions.

on actual client performance.
